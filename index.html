FEATURE

TBTが選ばれる理由

留学は人生を左右する大きな選択だからこそ、一人ひとりと向き合う時間を大切にしています。

サポート内容 提携校一覧
Feature 01

ICEF認定エージェントによる確かな手配力と最新情報

TBTは、世界中の教育関係者が集まる国際教育機関「ICEF」の厳しい審査をクリアした認定エージェントです。そのグローバルなネットワークを通じて、世界中の語学学校や大学と直接交流・情報交換を行っており、提携校は100校以上にのぼります。現地のリアルタイムな最新情報に基づき、質の高い確かなサポートをお客様にご提供しています。

Feature 02

パッケージにとらわれない「オーダーメイド留学」の実現

決まったプランをそのまま販売するのではなく、お客様一人ひとりの目的や夢に合わせた「オーダーメイドの留学」を手配できます。語学学校の選定にとどまらず、「現地のスポーツチームに参加したい」「観光などのアクティビティを組み込みたい」といった細かなご要望にも柔軟にお応えし、ご希望にぴったりの留学プランを構築します。

Feature 03

誰でも安心できる、きめ細やかで充実したサポート体制

未成年の方からシニアまで、すべての方が安心して留学生活を送れるよう、多岐にわたる徹底したサポートを提供しています。現地での日用品の買い物サポートや、ホストファミリーへの連絡、海外送金方法のご案内、現地SIMやWi-Fiの手続きなど「こんなことまでお願いできるの？」という細かなご要望にも寄り添い、留学のあらゆる不安を解消します。

Feature 04

英会話スクール併設ならではの「語学力向上・進学サポート」

TBTは英会話スクールも運営しており、代表はNPO留学協会認定の「RCA海外留学スペシャリストアドバイザー」資格を持つ現役の英会話講師です。オンラインで画面を共有しながらの英語書類作成サポートなどの渡航前準備から帰国後の進学相談まで、語学とキャリアの成長をシームレスに支援します。

Feature 05

営業時間外のLINE相談やテレビ電話対応など、徹底した「遠隔サポート」

単身での渡航でも、お客様を絶対に一人にはさせません。留学中に困ったことや不安なことがあれば、いつでもLINEでご相談いただけます。急な確認事項が生じた際には日本のスタッフが代わって現地の学校に電話で問い合わせるなど、他社にはない圧倒的にきめ細やかな遠隔サポートを提供しています。

Feature 06

学校からの紹介料に依存しない、中立的な経営スタイル

「手数料無料」のエージェントも、実は紹介先の学校からの紹介料が主な収益源です。そのため提携校以外は紹介しにくく、渡航後のサポートも手薄になりがちです。TBTは有料だからこそ紹介料に依存せず、本当にお客様に合った学校を中立的にご提案できます。
